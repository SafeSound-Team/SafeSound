# Navbar - SafeSound

## Descripción

Esta rama (`feature/navbar`) contiene el desarrollo del componente **Navbar** de la Landing Page de SafeSound.

El navbar fue diseñado para proporcionar una navegación clara e intuitiva entre las diferentes secciones de la página, permitiendo al usuario acceder rápidamente a la información principal del proyecto.

## Funcionalidades implementadas

- Logo de SafeSound ubicado en la parte izquierda.
- Menú de navegación con enlaces a:
  - Inicio
  - Problemática
  - Beneficios
  - Testimonios
  - Contáctanos
- Botón **"Modo IA"** ubicado en el extremo derecho.
- Diseño limpio y organizado.
- Barra de navegación responsive para distintos tamaños de pantalla.
- Efectos visuales al pasar el cursor sobre los enlaces.

## Tecnologías utilizadas

- HTML
- CSS

## Objetivo

El objetivo del navbar es mejorar la experiencia de navegación del usuario, ofreciendo acceso rápido a las principales secciones de la Landing Page de SafeSound mediante una interfaz sencilla, moderna y adaptable.

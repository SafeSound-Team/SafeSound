# SafeSound

## Descripción del Proyecto
SafeSound es un startup tecnológico enfocado en soluciones de seguridad urbana mediante IA. 
Nuestra aplicación móvil analiza el entorno sonoro en tiempo real para alertar a peatones 
sobre posibles riesgos mientras usan audífonos.

## Segmentos Objetivo
1. **Peatones urbanos con audífonos** — especialmente estudiantes, trabajadores y 
   personas con discapacidad visual parcial.
2. **Conductores, ciclistas y servicios de emergencia** — afectados por la falta 
   de percepción auditiva de los peatones.

## Características Principales
- Detección de sonidos críticos en tiempo real (bocinas, sirenas, frenadas)
- Alertas sin interrumpir la experiencia multimedia
- IA de reconocimiento de eventos de audio
- Diseño centrado en el usuario (seguridad + usabilidad)
